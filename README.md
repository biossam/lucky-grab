# LUCKY GRAB

키보드로 하는 고양이 크레인 뽑기 게임 (1인 · 2인).

- 2인: 파랑 `← →` 이동 · `SPACE` 집기 / 주황 `A D` 이동 · `S` 집기
- 꾹 누르면 더 깊이 내려가고, 20초가 지나면 자동으로 집어요.
- 황금 냥이 공은 3점!
- `M` 소리 · `Q` 화질 · `R` 공 채우기 · `H` 안내 · `F` 전체화면 · `ESC` 처음으로

## 우리 반 모드 (시작 화면 3번)

- **개인 차례:** 인원수와 빠진 번호(전학·결번)를 적으면 번호 순서나 무작위로 한 명씩 나와요. 결과 화면에 번호별로 맞힌 문제 수가 나와요.
- **모둠 대결:** 모둠 수와 바퀴 수를 정하면 모둠이 돌아가며 해요.
- **차례마다 기회:** 한 사람(모둠)이 쓸 수 있는 뽑기 횟수예요. 우리 반 모드에서는 기회가 늘지 않고, 퀴즈를 맞히면 **물고기 🐟**를 받아요(황금 냥이 문제는 2마리). 결과는 물고기 수로 순위를 매겨요.
- 문제를 다 쓰면 끝나지 않고, 틀린 문제부터 다시 섞어서 내요. 게임은 마지막 차례가 끝나야 끝나요.
- 결석한 학생은 `N`으로 건너뛰어요.
- 실수로 결과가 사라지지 않게, 우리 반 모드에서는 `ESC`(처음으로)와 결과 화면의 `Enter`(다시 하기)를 2초 안에 두 번 눌러야 해요.
- 결과 화면에는 상위 3명과 "모두 수고했어요"만 나와요. 번호별 물고기 수는 **번호별 보기 (선생님)** 버튼을 눌러야 보여요.
- 이름은 받지 않고 번호만 써요. 설정은 그 컴퓨터 브라우저에만 저장돼요(`luckygrab-class-v1`).

## 연산 퀴즈 (문제 뱅크)

`quizzes/math.html` — 시작 화면에서 **학년(3~6) · 학기 · 단원**을 고르면, 그 단원의 연산 문제가 판마다 새 숫자로 만들어져요.

- 문제 뱅크: `bank/math.js` (2022 개정 교과서 공통 연산 단원 25개). 정답은 직접 계산하고, 오답 보기는 자주 하는 실수로 만들어요.
- 문제가 떨어지지 않아요. 틀린 문제는 다시 나와요.
- 분수는 `{3/4}`, 대분수는 `{2|1/3}`로 쓰면 화면에 위아래 분수로 나와요 (다른 퀴즈 JSON에서도 쓸 수 있어요).
- 검사: `node tools/test_bank.mjs` — 단원마다 3,000문제씩 만들어서 모양·정답(따로 계산)·같은 값 오답을 확인해요.

## 뽑기 난이도

시작 화면에서 **쉬움(기본) · 보통 · 어려움**을 골라요. 쉬움은 공이 잘 잡히고 덜 떨어지며, 놓쳤을 때 가끔 "위로 문제"가 나와요. 고른 난이도는 학생 QR에도 담겨요.

## 학생 기기로 하기 (QR)

- 시작 화면 오른쪽 아래 **학생 QR** 버튼(또는 `G` 키)을 누를 때만 QR이 크게 떠요. 닫으면 사라져요.
- 서버가 없어서, 이미 주소를 받은 학생이 나중에 다시 들어오는 것까지 막지는 못해요(혼자 연습만 돼요).
- 학생이 찍으면 같은 퀴즈가 `?mode=student`로 열려요. 연산 퀴즈는 선생님이 고른 학년·학기·단원이 주소에 담겨서 그대로 나와요.
- 학생 화면에는 1인용만 있고, 휴대폰·태블릿에서는 화면 버튼(◀ 집기 ▶)으로 해요. 학생 기기의 설정은 저장하지 않아요.
- 서버가 없어서 학생들의 결과가 선생님 화면으로 모이지는 않아요.
- QR 그리기: `vendor/qrcode/` (qrcode-generator, MIT)

## 새 퀴즈 만들기

1. `quizzes/<이름>.json`에 문제를 써요 (`quizzes/circle.json` 참고).
2. `python3 tools/make_quiz.py quizzes/<이름>.json` → `quizzes/<이름>.html`이 만들어져요. 정답 번호, 같은 문제, 빈 칸을 자동으로 검사해요.
3. 틀(`index.html`)을 고친 뒤에는 `python3 tools/make_quiz.py --all`로 모든 퀴즈를 다시 만들어요.

## 퀴즈 모드

공을 뽑아 통에 넣으면 퀴즈가 나와요. 맞히면 뽑기 기회가 늘어나요. 기회를 다 쓰거나 문제를 다 풀면 결과 화면이 나와요.

`index.html` 아래쪽의 `<script type="application/json" id="quiz-data">` 부분만 바꾸면 새 퀴즈 게임이 돼요.

| 칸 | 뜻 |
|---|---|
| `title` / `subtitle` | 시작 화면 제목 · 설명 |
| `settings.startTries` | 처음 뽑기 기회 (기본 3) |
| `settings.bonusTries` | 맞혔을 때 늘어나는 기회 (기본 2) |
| `settings.goldBonusTries` | 황금 냥이 공 문제를 맞혔을 때 (기본 3) |
| `settings.turnSeconds` | 자동으로 집기까지 시간 (기본 20) |
| `settings.shuffle` | 문제 순서 섞기 (판마다) |
| `settings.shuffleChoices` | 객관식 보기 순서 섞기 (문제마다, OX는 그대로) |

문제 종류: `choice`(객관식, `answer`는 **써 놓은 보기 순서**로 1부터 세는 번호 — 화면에서는 섞여 나와도 정답은 알아서 맞춰져요) · `ox`(`answer`는 `"O"`/`"X"`) · `open`(주관식, 정답을 보여 주고 선생님이 맞음/틀림을 눌러요). `explain`(풀이)과 `image`(그림)는 넣지 않아도 돼요.

`questions`를 비우면(`[]`) 퀴즈 없이 그냥 뽑기 게임이 돼요.

## 보안 메모

- 3D 그림 도구 three.js(r169, MIT 라이선스)는 외부 사이트에서 불러오지 않고 `vendor/three/`에 넣어 두고 써요. `biossam.github.io` 아래 다른 사이트(성장 MAP 등)와 브라우저 저장 공간을 같이 쓰기 때문이에요.
- 모든 페이지에 `noindex`를 넣어 검색 엔진(구글·네이버 등) 결과에 나오지 않게 했어요. 주소를 아는 사람만 들어올 수 있어요.
- 페이지 주소가 외부(Google 글꼴)에 전달되지 않게 `referrer`를 막았어요.
- 각 페이지에는 보안 정책(CSP)이 들어 있어요. 이 저장소 밖의 스크립트, 그림, 통신은 막혀요(글꼴만 Google Fonts에서 받아요).
- `quizzes/` 폴더의 퀴즈는 `../vendor/three/`를, 루트의 `index.html`은 `./vendor/three/`를 불러와요.
- 문제 그림(`image`)은 저장소 안 파일이나 `data:` 그림만 쓸 수 있어요.
